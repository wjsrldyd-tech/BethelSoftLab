# 가정예배서 작성기

벧엘시스템 스타일의 가정예배서를 디지털로 생성하고 출력할 수 있는 웹 애플리케이션입니다.

## 기능

- ✅ 8페이지 가정예배서 작성
- ✅ 실시간 미리보기
- ✅ JSON 파일로 저장/불러오기
- ✅ PDF 다운로드
- ✅ 이미지 업로드 (표지, 악보, 말씀 이미지)

## 설치 및 실행

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하세요.

### 3. 빌드

```bash
npm run build
```

## 사용 방법

1. **입력**: 좌측 입력 영역에서 각 페이지별로 내용을 입력합니다.
   - 1페이지: 표지 (날짜, 제목, 설교제목, 표지그림)
   - 3페이지: 경배와 찬양 (악보 이미지)
   - 5페이지: 찬양 (악보 이미지)
   - 6페이지: 예배기도 및 말씀
   - 7페이지: 나눔 및 마침기도

2. **미리보기**: 우측 미리보기 영역에서 실시간으로 확인할 수 있습니다.
   - 탭을 클릭하여 페이지를 전환할 수 있습니다.
   - 이전/다음 버튼으로도 이동 가능합니다.

3. **저장**: "파일로 저장" 버튼을 클릭하여 JSON 파일로 저장합니다.
   - 파일명은 자동으로 생성됩니다: `가정예배_YYYY-MM-DD_제목.json`

4. **불러오기**: "불러오기" 버튼을 클릭하여 저장한 JSON 파일을 불러옵니다.

5. **PDF 출력**: "PDF 다운로드" 버튼을 클릭하여 8페이지 전체를 PDF로 다운로드합니다.

## 기술 스택

- React 18 + TypeScript
- Vite
- Zustand (상태 관리)
- Tailwind CSS
- jsPDF + html2canvas (PDF 생성)
- date-fns (날짜 처리)

## 프로젝트 구조

```
src/
├── components/          # 컴포넌트
│   ├── inputs/         # 입력 필드 컴포넌트
│   └── preview/        # 미리보기 컴포넌트
├── stores/             # Zustand 상태 관리
├── types/              # TypeScript 타입 정의
├── utils/              # 유틸리티 함수
└── App.tsx            # 메인 컴포넌트
```
